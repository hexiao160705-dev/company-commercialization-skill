# 验证用户能否完成核心操作

牵头：产品部。输入：目标用户、核心任务与界面原型。

## 完成条件

走查成功、错误和恢复路径；按影响排序可用性问题，把设计状态和文案交给开发。



## 根据当前缺口选用

- 评审设计是否支持用户目标 → [design-critique](../../references/sources/knowledge-work-plugins/design/skills/design-critique/SKILL.md)
- 检查无障碍使用障碍 → [accessibility-review](../../references/sources/knowledge-work-plugins/design/skills/accessibility-review/SKILL.md)
- 统一组件与交互规范 → [design-system](../../references/sources/knowledge-work-plugins/design/skills/design-system/SKILL.md)
- 编写界面提示、错误和按钮文案 → [ux-copy](../../references/sources/knowledge-work-plugins/design/skills/ux-copy/SKILL.md)
- 交接界面状态与实现细节 → [design-handoff](../../references/sources/knowledge-work-plugins/design/skills/design-handoff/SKILL.md)
- 标出客户旅程的触点和障碍 → [customer-journey-map](../../references/sources/pm-skills/pm-market-research/skills/customer-journey-map/SKILL.md)
- 编辑营销文案并校对表达 → [copy-editing](../../references/sources/marketingskills/skills/copy-editing/SKILL.md)
